The World in One Day — Thursday 19 November 2026. One newspaper front page that sums up the whole day's world news: 46 stories from six continents, every one dated to 19 November 2026 and carrying its source. Three lead stories (the World Court's Rohingya genocide ruling, the Trump–Xi–Putin Shenzhen summit, and Anthropic's record IPO) carry drawn illustrations; seven regional sections and an "In brief" strip carry the rest. The page is drawn by `make-image.py` (Python + Pillow) into `entry.png`; `main.ts` copies that file to the output directory unchanged.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
